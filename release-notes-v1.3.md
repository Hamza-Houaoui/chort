# CHORT v1.3 - Release Notes

**CHORT (formerly Podium Music Player)** - The retro iPod-inspired music player engineered for modern Android.

## What's New in v1.3

### 🎨 Complete Rebranding to CHORT
- **App Identity:** Full rebrand to **CHORT** with brand-new glossy neon equalizer app icon & boot screen.
- **Customizer & Settings:** Updated references, "CHORT ART" stickers and finishes, live sound settings, and "CHORT by Hamza Houaoui" software update panel.
- **Boot Animation:** Modernized startup sequence showcasing the new neon CHORT equalizer aesthetic.

### 🎙️ Full Podcasts Experience
- **Home Menu Placement:** "Podcasts" right on the main menu below Radio (Music, Online, Radio, Podcasts, Listen Together, Voice Memos, Settings).
- **Triple Provider Engines:**
  1. **Apple Podcasts / iTunes:** Free out-of-the-box search without any API keys, millions of global and regional shows.
  2. **YouTube Music Podcasts:** Native search & streaming via the app's existing YouTube Music source!
  3. **Podcast Index:** Built-in client with optional custom API Key & Secret support.
- **Direct RSS Feed URL:** Add any independent or private podcast feed instantly by pasting its RSS URL.
- **Top Charts & Regional Filtering:** Browse trending shows in Tunisia 🇹🇳, Arab World 🇸🇦, France 🇫🇷, and Global/US 🌐.
- **Categories & Genres:** News, Comedy, Technology, Religion & Spirituality, True Crime, Sports, Business, Science, History, Arts.
- **Subscriptions & Resume Position:** Save favorite shows and resume long episodes exactly where you left off.
- **Click Wheel Controls:** Full scrub, seek, play/pause, and lock-screen background playback.

### 📻 In-App Live Radio Mini-Browser
- **Radio Web View:** Browse stations' live web pages, read retro news, track playlists, and watch live streams directly on the iPod virtual screen.
- **Click Wheel Scrolling:** Effortlessly scroll web pages up and down using the touch Click Wheel.
- **Seamless Navigation:** Press `MENU` anytime to return immediately to the live radio Now Playing screen.
- **Action Tray Integration:** Dedicated `Web` action button in the live radio player controls.
- **Station Link Editor:** Edit and customize the website URL for any radio station directly from the Edit Station and Add Custom Station dialogs.

### 📱 Maximized Screen Layout
- **Expanded Virtual Display:** Virtual iPod screen has been significantly enlarged for maximum immersion, richer album art display, Cover Flow, and web browsing.
- **Streamlined Hardware Face:** Top power button and LED indicators hidden for a cleaner, modern full-screen iPod look.

### 🔍 Optimized Navigation Flow
- **Online Screen:** Reordered sections to prioritize **Search** right at the top, followed by Cover Flow.
- **Radio Screen:** Reordered hierarchy with **Search** at the top, followed by Cover Flow and Favorites.
